# MIA · Mapa de desafíos (app de stand)
- `index.html`: experiencia web (elige desafío → toca tu estado → cuéntanos → WhatsApp/correo).
- `resultados.html`: tabla + descarga Excel/CSV (clave en variable de entorno `ADMIN_KEY` de Netlify) y respaldo local del dispositivo.
- `backend-netlify/`: Netlify Function + Blobs (`/api/registro`, `/api/mapa`, `/api/datos`).
